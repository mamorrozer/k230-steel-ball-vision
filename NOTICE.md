# Public release boundary

This repository is a curated engineering extract for portfolio review. It contains selected personal scripts, portable control helpers, deployment examples and measured results from a K230 steel-ball vision experiment.

The public copy excludes image datasets, annotations, model weights, KModel/ONNX files and training outputs; vendor SDKs, board system libraries and third-party application bundles; private paths, credentials, raw experiment captures and unrelated contest materials; and the unfinished motor-control closed loop.

This repository does not grant a license to omitted assets or third-party components. The selected source is published for technical review and portfolio presentation. An explicit open-source license should be added only after the provenance of every included file has been confirmed.
